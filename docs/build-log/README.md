# Build log

This folder records how Stay In Touch was built: what each handoff asked for, which agents built and reviewed it, what shipped, what review found, and which decisions were made.

## Naming

Each entry is a markdown file named **`NN-short-slug.md`**: a two-digit sequence number (zero-padded) and a short kebab-case slug, for example `01-repo-skeleton-and-database.md`.

Add the next number in order. Do not renumber or rename old entries.

## Template

Copy [`_template.md`](./_template.md) when starting a new entry. Keep entries short and scannable.
