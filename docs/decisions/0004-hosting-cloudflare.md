# Cloudflare for frontend hosting

## Context
The prototype should stay on free tiers; the app is commercial family software.

## Options considered
- Vercel free (commercial use restricted on free plan).
- Netlify (credits deplete quickly with frequent agent deploys).
- Cloudflare (free tier for static/PWA assets).

## Decision
Host the PWA on Cloudflare.

## Consequences
Aligns with R2 for media in the same vendor ecosystem. Planned, not deployed yet.

## Status
Accepted
