# Grandparents may post media in child spaces

## Context
Grandparents participate in children's rooms without their own space.

## Decision
Grandparents may post photos and videos in a child's space (same as text).

## Consequences
Grandparent posting uses the same RLS paths as in any viewable space. Verified by role design in architecture.

Accepted
