# Icons from one SVG, no iOS splash set

## Context
The manifest needs 192, 512, a maskable 512, an opaque apple touch icon, and a 96px badge. An iOS splash image set is dozens of files.

## Options considered
- `@vite-pwa/assets-generator` at build time.
- Commit PNGs generated by `scripts/pwa-icons.mjs` from `web/public/icon.svg`.

## Decision
Commit the PNGs. The script uses Node's zlib and has no native dependency. Maskable art is padded. The apple touch icon is opaque 180px. Theme color is `#f7f5f2` (dark `#12100e`). There is no splash-image set.

## Consequences
Changing the mark means re-running the script and committing the PNGs. Install screens do not get a custom iOS launch image.
